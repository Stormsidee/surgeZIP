# ModernArchiver

Современный архиватор на Python с поддержкой популярных форматов: ZIP, RAR, 7Z, TAR, GZ, BZ2, ISO.

## Возможности

- Просмотр содержимого архивов с навигацией по папкам
- Извлечение файлов и папок
- Drag-and-drop для извлечения файлов
- Темный интерфейс
- Поддержка популярных форматов архивов

## Установка

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Запустите приложение:
```bash
python main.py
```

## Регистрация ассоциаций файлов (Windows)

Для интеграции с Windows Explorer:

1. Запустите скрипт регистрации с правами администратора:
```bash
python register.py
```

2. Выберите "1" для регистрации.

Это позволит:
- Открывать архивы двойным кликом в вашем приложении
- Использовать "Extract to..." в контекстном меню архивов
- Использовать "Compress with ModernArchiver" в контекстном меню файлов/папок

## Сборка в EXE

```bash
pyinstaller --windowed --onefile -name=ModernArchiver main.py
```

## Использование

- Перетащите архив в окно приложения или укажите путь в командной строке
- Используйте кнопки навигации для перемещения по архиву
- Выберите файлы/папки и нажмите "Извлечь" или используйте контекстное меню
- Для создания архивов используйте контекстное меню в проводнике

## Поддерживаемые форматы

- .zip
- .rar (требует rarfile)
- .7z (требует py7zr)
- .tar
- .gz
- .bz2
- .iso (требует pycdlib)
